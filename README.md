# CareBridge

A university Flask project for a discharge summary access website.

## Setup

```powershell
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
flask --app app init-db
python app.py
```

Open:

```text
http://127.0.0.1:5000
```
